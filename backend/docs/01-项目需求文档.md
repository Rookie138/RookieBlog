# 个人博客系统需求文档



## 1. 项目介绍

###  1.1 项目背景

本项目是一个个人博客系统，用于记录和分享自己学习感悟、以及一些技术文章。

系统包含后端管理管理端和用户访问端。

管理员可以管理发表文章、分类、标签等

普通用户可以浏览文章、发表评论



### 1.2 项目目标

实现一个完整的个人博客系统：

- 用户认证
- 文章管理
- 评论管理
- 权限控制



## 2. 功能需求拆解

### 2.1 用户模块

管理员：

- 管理员登录
- 查看普通用户列表
- 管理普通用户状态
- 管理角色权限

普通用户：

- 用户注册
- 用户登录
- 查看个人信息
- 修改头像
- 修改密码

### 2.2 文章模块

管理员：

- 创建文章
- 修改文章
- 删除文章
- 发布文章
- 查看文章列表

普通用户：

- 浏览文章
- 搜索文章
- 查看文章详情

### 2.3 评论模块

管理员：

- 审核评论
- 删除违规评论

普通用户：

- 发表评论
- 删除自己的评论
- 查看评论

## 3.非功能需求

### 性能

系统能够支持一定数量的用户同时访问。

### 安全

用户密码需要加密保存

接口需要身份认证（或者限制爬虫无限制地爬取）

防止DOS功能导致服务器瘫痪

### 可维护性

代码采用模块化设计

业务逻辑和数据库操作分离
