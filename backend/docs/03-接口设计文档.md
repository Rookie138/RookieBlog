# 接口设计文档

### 用户相关接口

| 接口               | 方法 | 说明         |
| ------------------ | ---- | ------------ |
| /api/user/register | POST | 用户注册     |
| /api/user/login    | POST | 用户登录     |
| /api/user/info     | GET  | 获取用户信息 |
| /api/user/update   | PUT  | 更新用户信息 |
| /api/user/password | PUT  | 修改用户密码 |



### 文章相关接口

| 接口                   | 方法 | 说明         |
| ---------------------- | ---- | ------------ |
| /api/article/list      | GET  | 获取文章列表 |
| /api/article/detail/id | GET  | 获取文章     |
|                        |      |              |
